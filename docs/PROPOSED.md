# Proposed

Ideas from the builder. Nothing here is built until the product owner approves it by name.

## Phase 1
Approved and built: Percentage key helper, Previous observation peek, Ready-to-complete check.

1. **Lesson timer and time-stamped notes.** Start a timer when the lesson begins. Quick notes are stamped
   "12 min" and can be moved onto a criterion as its comment.
2. **Evidence phrase chips.** Short phrases per criterion, written by Ms. Ayan and Ms. Marwa (never generated),
   that can be tapped into a comment.
3. **Install as a phone app.** Opens from the home screen and loads with no signal, so the form can be started
   in a classroom with poor reception.
4. **Two-device warning.** If the same observation is open on two phones, the observer is warned before both
   edit at once.
5. **Sign-in protection.** Slow down repeated wrong passwords per username, and show admin the last sign-in time
   per person.
6. **Period times.** Add the school's bell times, so visits show "Period 3 · 09:40" and the Time box fills
   itself.
7. **"Last time" marker.** While rating, a small marker shows the level this teacher received last time for
   that criterion.
