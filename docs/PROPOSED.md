# Proposed

Ideas from the builder. Nothing here is built until the product owner approves it by name.

## Phase 1
Approved and built: Percentage key helper, Previous observation peek, Ready-to-complete check.

1. **Lesson timer and time-stamped notes.** Start a timer when the lesson begins. Quick notes are stamped
   "12 min" and can be moved onto a criterion as its comment.
2. **Evidence phrase chips.** Short phrases per criterion, written by Ms. Ayan and Ms. Marwa (never generated),
   that can be tapped into a comment.
3. **Install as a phone app.** Opens from the home screen and loads with no signal, so the form can be started
   in a classroom with poor reception.
4. **Two-device warning.** If the same observation is open on two phones, the observer is warned before both
   edit at once.
5. **Sign-in protection.** Slow down repeated wrong passwords per username, and show admin the last sign-in time
   per person.
6. **Period times.** Add the school's bell times, so visits show "Period 3 · 09:40" and the Time box fills
   itself.
7. **"Last time" marker.** While rating, a small marker shows the level this teacher received last time for
   that criterion.

## Phases 2 to 4
1. **Evidence links:** each AI line shows the rating or comment it came from.
2. **Read receipt on the visits list:** a small mark when a teacher has opened their feedback.
3. **Reflection prompts:** 2 or 3 guided questions for the teacher, based on their improvement areas.
4. **Send all at once:** share every completed observation from a day in one action.
5. **Signing reminder:** an in-app nudge if a teacher hasn't signed after 3 days.
6. **Workshop materials:** an AI-drafted one-page outline for each suggested workshop, using only the rubric
   wording and the school's own data.
7. **Grade band comparison:** KG, Lower Primary and Upper Primary side by side on the dashboard.
8. **Observer consistency check:** how differently Ms. Ayan and Ms. Marwa rate the same criteria, to support
   moderation.
9. **Termly report for leadership:** a printable summary of progress, workshops and pairings across a term.

## Welcome and guides
1. **Short screen recordings.** A 20-second silent clip per role (rate, draft, share) that plays in the welcome story
   in place of the drawn example.
2. **Arabic welcome for coordinators too.** The same Arabic line under each part, if Ms. Ayan or Ms. Marwa would
   like to show it to Arabic-speaking staff.
3. **"What's new" card.** After an update, a one-card story that shows only what changed, then gets out of the way.
4. **Checklist for the administrator.** Try each role, open the dashboard, export once, then Go live: ticked as it
   happens, ending on the Go live button.
5. **Printable one-page guide.** The four steps for observers and teachers on one A4 page, for the staffroom
   noticeboard.
